# 💱 Currency Converter

A simple and practical **Python Currency Converter** that allows users to convert amounts between different currencies using exchange rates.

This project was built to practice working with **APIs, user input, JSON data, and Python functions** while creating a useful real-world application.

## ✨ Features

* 💱 Convert between different currencies
* 🌐 Fetch exchange rates from an online API
* 🔢 Enter any amount for conversion
* 🔄 Select source and target currencies
* 📊 Calculate the converted amount automatically
* ⚠️ Handle invalid input and API errors
* 🐍 Built entirely with Python

## 🛠️ Technologies Used

* **Python**
* **REST API**
* **JSON**
* **Requests Library**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/subashbhusal/Currency-Converter.git
```

### 2. Open the project directory

```bash
cd Currency-Converter
```

### 3. Install the required library

```bash
pip install -r requirements.txt
```

Or:

```bash
pip install requests
```

### 4. Run the program

```bash
python currency_converter.py
```

## 💻 Example

```text
==============================
      CURRENCY CONVERTER
==============================

Enter amount: 100

From currency: USD
To currency: NPR

100 USD = 15,346 NPR
```

*Exchange rates change continuously, so the displayed result may vary.*
